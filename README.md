# Rock Paper Scissors

A Python-based Rock Paper Scissors game developed as one of my first programming projects.

## Features

* Rock, Paper and Scissors gameplay
* Randomized computer choices
* Win, loss and draw tracking
* Win/Loss ratio calculation
* Input validation
* Replay functionality

## How It Works

The player chooses Rock, Paper or Scissors. The computer randomly selects one of the three choices.

The program then determines the outcome:

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Matching choices result in a draw

## Statistics

At the end of the game, the program displays:

* Total games played
* Total wins
* Total losses
* Total draws
* Win/Loss ratio
